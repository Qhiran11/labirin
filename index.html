Cara Bermain WAVE UP

  1. Pilih Arah Gerak:
    • Menggunakan Sensor (HP): Aktifkan sensor orientasi. Arah hadapan karakter Anda di labirin akan berputar sesuai arah Anda memutar HP Anda secara horizontal. Gunakan tombol "Kalibrasi Depan" untuk menyelaraskan arah hadapan HP saat ini sebagai arah "Lurus Depan".
    • Menggunakan Keyboard (PC): Tekan tombol A atau Arrow Left untuk berputar ke kiri, tombol D atau Arrow Right untuk berputar ke kanan.
  2. Berjalan Maju:
    • Tahan tombol "TAHAN UNTUK JALAN" di layar.
    • Atau tekan tombol W / Arrow Up pada keyboard komputer Anda.
    • (Opsional) Jika kamera diaktifkan, gerakan vertikal ponsel (bobbing guncangan seperti melangkah lari) akan dihitung untuk menambah kecepatan berjalan Anda di labirin secara real-time!
  3. Menjawab Soal:
    • Lihat Legenda Jawaban di bawah labirin. Setiap pilihan jawaban diwakili oleh kotak berwarna yang memiliki Label Huruf (A, B, C, D).
    • Cari ruangan berlabel huruf tersebut di dalam labirin. Arahkan karakter Anda untuk memasuki ruangan tersebut.
    • Jika benar, Anda mendapat +1.0 poin dan berlanjut ke labirin/soal berikutnya. Jika salah, skor berkurang -0.1 poin dan ruangan jawaban salah tersebut akan dihancurkan, sehingga Anda dapat mencari jawaban lain.
  4. Selesaikan ke-10 pertanyaan dengan skor tertinggi untuk mencatatkan waktu terbaik Anda!
